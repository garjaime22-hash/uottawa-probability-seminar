# Young Researchers in Probability

A small, mobile-friendly seminar website hosted with GitHub Pages. The public site uses plain HTML, CSS, and JavaScript, with no packages or build step.

For ordinary schedule updates, follow [`EDITING-GUIDE.md`](./EDITING-GUIDE.md). All seminar content is kept in [`site-data.js`](./site-data.js).

## Publishing

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the `main` branch and `/(root)` folder.
